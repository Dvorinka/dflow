# Introduction

dFlow is a platform for deploying, managing, and scaling git apps, Docker
images, and databases on your own infrastructure.

This is the community-maintained fork of dFlow. The upstream project is no
longer maintained; this fork is developed independently and is fully open
source — no hosted tier, no feature gates, no external service dependency.
Everything runs on infrastructure you own.

## Key Features

- **Easy to use**: dFlow provides a simple and intuitive interface for managing
  your applications and infrastructure.
- **Fast**: dFlow is designed to be fast and efficient, allowing you to deploy
  and manage your applications quickly.
- **Flexible**: dFlow supports a wide range of applications and infrastructure
  components, making it easy to integrate with your existing tools and
  workflows.
